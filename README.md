## Как устроено

Брифы и макеты — статические HTML-страницы без сборки. `prototype/` — готовая сборка прототипа: её кладёт скрипт `scripts/publish-prototype.sh` из закрытого репозитория проекта, руками её не правят. Всё публикуется через GitHub Pages из ветки `main`. Локально: `python -m http.server` в корне и открыть `http://localhost:8000/`. Канвас (`canvas.html`) встраивает макеты из `mockups/` через iframe, поэтому с `file://` подписи и высоты работают хуже — лучше через локальный сервер.
