# ATV Jarvis — брифы и макеты

Рабочие материалы по ATV Jarvis — системе постановки и контроля задач для ATV Group: руководитель ставит задачи текстом или голосом, сотрудники работают через Telegram-бота.

**Смотреть:** https://baslie.github.io/atv-jarvis-public/

- [Брифы Тимофея и Василия](https://baslie.github.io/atv-jarvis-public/briefs.html) — что хочет каждый директор, расхождения, общие места и открытые вопросы.
- [Макеты интерфейса](https://baslie.github.io/atv-jarvis-public/canvas.html) — все макеты на одном канвасе: приложение для компьютера, Telegram-бот, пограничные ситуации. Мышь или палец — двигать полотно, Ctrl + колесо или щипок — масштаб, клик по макету — открыть его целиком.

Материалы от 2026-10-27. Макеты очень примерные: про смысл, а не про пиксели. Имена сотрудников, отделы и проекты на макетах — примеры.

## Как устроено

Статические HTML-страницы без сборки, публикуются через GitHub Pages из ветки `main`. Локально: `python -m http.server` в корне и открыть `http://localhost:8000/`. Канвас (`canvas.html`) встраивает макеты из `mockups/` через iframe, поэтому с `file://` подписи и высоты работают хуже — лучше через локальный сервер.
